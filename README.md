# UN6C: United Nations Sixth Committee English–Arabic Parallel Corpus

UN6C is a document-centred English–Arabic parallel corpus of 1,957 bilingual Sixth Committee document identities, covering General Assembly sessions 45–79 (1990–2024).

## Version 1.0

**[Access the v1.0 corpus dataset](releases/v1.0/README.md)** — full review-inclusive corpus correspondences, source-linked frozen records, document and review metadata.

The release includes all admitted bilingual documents.
