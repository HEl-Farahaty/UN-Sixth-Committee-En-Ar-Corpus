# UN6C: United Nations Sixth Committee English–Arabic Parallel Corpus

UN6C is a document-centred English–Arabic parallel corpus of 1,957 bilingual Sixth Committee document identities, covering General Assembly sessions 45–79 (1990–2024).

## Version 1.0

**[Access the v1.0 corpus dataset](releases/v1.0/README.md)** — full review-inclusive corpus correspondences, source-linked frozen records, document and review metadata, and SHA-256 checksums.

The release includes all admitted bilingual documents regardless of whether document review is finished, in progress, or not yet recorded. Review status is metadata, **not** a declaration of independently verified translation accuracy. The current website correspondence layer and the older frozen source-linked layer are distributed separately; see the dataset README for provenance and limitations.

The 23 October 2026 saved review snapshot is the latest included in this version. Later corrections will be released in separately versioned updates.
